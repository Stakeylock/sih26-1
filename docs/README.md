## Repository hygiene

`scratch-visual/` and `work/` contain historical visual review captures, not frontend assets or required production services. The synthetic PDFs under `public/samples/` **are** part of the demo and should not be deleted. Avoid committing generated logs, credentials, Docker state, browser traces or local environment files.

When documenting new measurements, capture the run date, revision, data source, environment, exclusions and reproduction command. Do not silently replace a failed run with an older successful result.
