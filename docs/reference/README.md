# Handbook clause reference

`APH_2024-27.txt` is the text extraction of the AICTE Approval Process Handbook
2024-25 to 2026-27 used to verify the clause numbers and quoted text in
`src/domain/aph.ts`.

It is reference material for this synthetic prototype only. Clauseway is not an
official AICTE service, and nothing here is an official AICTE citation.

## Use

1. Grep `APH_2024-27.txt` for the norm you are about to encode.
2. Take the clause number exactly as written, for example `APH 6.17(i)`.
3. If the handbook does not say it, do not invent it.
4. Keep the "demonstration references only" wording on seeded data.

The handbook is published by AICTE and is not ours to relicense.
